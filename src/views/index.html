How it works

Move text, images and files between computers that can't reach each other. No account needed.

  1. 1
    Open or create a stash

    Type a name on the left and press Open. If it does not exist yet you can create it. Leave the box empty for a random name.

  2. 2
    Open the same link on your other machine

    Use the stash's address (/s/name), or press QR code in the stash to open it on a phone.

  3. 3
    Add a note, a file or a screenshot

    Type in the note box, use the paperclip, drag files onto the page, or paste a screenshot with Ctrl + V.

  4. 4
    Copy it on the other side

    It appears straight away, with no refresh. Press Copy latest (Alt + C) for the newest note, or download a file.

Good to know

  • Private? Open More options and set a password. Then share a read-only or drop-box link from the stash.
  • Temporary. A stash and everything in it is deleted when its time is up (1 hour to 30 days). You can extend it.
  • Sensitive note? Choose Burn after reading to show it once, or Secret to hide it as dots.
  • Mistake? Deleted items can be undone for a couple of minutes.
  • Have an account? Your stashes are under My stashes in the menu.
