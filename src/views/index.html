New stash

A link two machines can both open to trade text, images and files.
Only the admin can create stashes on this server. Sign in as admin to create one. You can still open a stash you have the link to.
Anyone with the name can open the stash. Letters, numbers, - and _.

How it works

  1. Create a stash and open its link on both machines.
  2. Add a note, drop a file, or paste a screenshot on one machine.
  3. It shows up on the other machine straight away, ready to copy or download.
