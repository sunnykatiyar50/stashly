Set password

Setting a password signs everyone out of the stash and cancels its read-only and drop-box links. The notes and files are not touched. Whoever knows the new password can open the stash, you included, so only do this when the owner asks or the stash must be recovered.

Set owner

The user becomes the owner: the stash is always in their My stashes, they open it with no password, and they can change its password and pass it on. People already using it keep the access they have. Only an owner can pass a stash on later, so this cannot be changed from here afterwards.
