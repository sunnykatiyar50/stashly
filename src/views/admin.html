Settings

Limits apply straight away and are kept across restarts. Reset returns them to the server's environment values.

Set password

Setting a password signs everyone out of the stash and cancels its read-only and drop-box links. The notes and files are not touched. Whoever knows the new password can open the stash, you included, so only do this when the owner asks or the stash must be recovered.

Reset password

Sets a new password and signs the user out everywhere. Tell them the new password.
